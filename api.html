API docs

There is no server to call. The whole directory is one JSON file, and the site itself reads it. You can read it too.

Endpoint

GETdata/tools.json

It returns an array of tool objects. No key, no auth, no query parameters. Filter and sort in your own code.

Try it

Press the button to load the first tool.

A tier in pricing.tiers is {n, p, d}: plan name, price as the vendor shows it, and a short note.

  


  

    
What to expect

    
    
      
  • It is read-only and it is a static file. There are no rate limits because there is no server logic, and no uptime promise either.
    • 
      
  • Fields can change. Look at the changelog when something breaks.
    • 
      
  • Reading it from another website needs the host to allow cross-origin requests. If your fetch is blocked, download the file and serve your own copy.
    • 
      
  • Prices are only as fresh as pricing.verified. Where it is null, we could not confirm the number on the vendor's page.

  • Please credit AutomationFindr and link back. See the terms.
